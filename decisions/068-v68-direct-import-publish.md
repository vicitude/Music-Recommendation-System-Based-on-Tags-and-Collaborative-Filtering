# v68 同页导入并发布及批次恢复

对应BACKLOG #007。用户反馈发布页0首、找不到跳转且反对强制先保存草稿再发布，授权简化流程。

批次结果由save_batch写磁盘，发布页仅查询未发布Song，两者不是同一份列表。未读取真实数据库，无法据截图认定草稿曾入库或丢失；不能将会话失效与持久数据删除混为一谈。

主流程改为分析完成后明确确认“一键导入并发布新歌”，内部复用publish_song校验，创建歌曲/写标签/发布同事务，失败回滚并记录可能未关联音频，不自动删除。已有歌曲不覆盖，已有草稿保留独立批量发布入口；只存草稿折叠可选。新增按账号隔离最近10批次恢复入口，空发布页解释候选与曲库区别。

24项针对测试、全后端383项、脚本12项及规格环境门禁通过，覆盖直接发布成功/失败回滚、重复不覆盖、最近批次归属及持久加载。无新依赖/迁移，无真实库/模型写入或音频复制，测试使用隔离文件和内存SQLite；未进行实机浏览器或独立复核。
