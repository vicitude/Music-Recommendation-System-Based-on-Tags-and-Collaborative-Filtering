# v37 反馈矩阵与标签级 TF-IDF 内容推荐

- 日期：2026-11-07。
- 状态：已实现，真实 MySQL 迁移与浏览器业务验收待单独执行。
- 关键词：反馈矩阵、评分映射、标签级 TF-IDF、内容画像、低评分排除、截止时间。
- 关联模块：推荐、评分、收藏、播放行为、标签、每日推荐。
- 变化程度：推荐纯计算引擎和每日推荐数据装载更新；不接入 Item-CF、场景权重、多样性重排或新的前端行为。

## 摘要

阶段 2 已完成。收藏、播放完成和评分现在进入统一反馈矩阵；标签内容推荐改为标签级 TF-IDF 向量和余弦相似度，用户画像同时使用手选兴趣与正向反馈歌曲标签。低评分歌曲进入目标用户排除集，评分 3 分保持中性，不污染正向画像。

## 固定规则

- 收藏映射为 5，播放完成映射为 3，评分 5/4/3/1—2 分别映射为 5/4/0/-1。
- 同一反馈类型按用户/歌曲去重，不重复累加；不同反馈类型按映射值相加。
- 推荐计算严格使用 `occurred_at < cutoff`；截止时刻及之后的反馈不参与矩阵、画像、协同分或排除集。
- 每个有效标签 ID 是一个 TF-IDF token，歌曲标签去重；使用平滑 IDF，歌曲向量 L2 归一化，无标签歌曲保持空向量。
- 当前阶段仍使用既有 User-CF 与融合入口，Item-CF、场景动态权重和多样性优化留到后续阶段。

## 实现

- `backend/music/recommendation.py` 新增评分信号、标签级 TF-IDF 向量构造和带 IDF 的用户画像计算。
- `backend/music/daily.py` 在推荐适配层读取评分并构造 `TimedRating`，不改变每日快照读取过滤和收藏保留规则。
- 低评分歌曲不会作为目标用户的推荐候选；评分 3 分既不进入正向矩阵，也不作为内容画像来源。
- 阶段二没有新增依赖、迁移或前端页面改动。
