# v70 后台首页快捷入口与授权卡布局

## 背景
用户反馈新加的批量扫描、批量发布、已发布清单、标签库和推荐诊断入口不容易发现；Django认证与授权区域的“组”卡片在只有一个模型时被拉成整行，视觉上空且冗长。

## 处理
- 首页增加“常用操作”横向快捷卡：扫描并批量打标签、批量发布歌曲、查看已发布歌曲、标签词库、推荐算法诊断；仍按当前账号权限显示。
- 管理入口中过滤`Group`模型，避免把低频授权对象当作主业务模块展示；认证授权卡使用更紧凑的尺寸。
- 桌面端五列、窄屏三列、手机单列；静态资源版本更新为20261110-1。

## 验证与边界
- `music.test_admin_ui`：14项通过，覆盖管理员首页、权限隔离、入口文本、样式缓存版本及已有布局约束。
- `verify_spec.py --self-test --check-environment`：文档和环境门禁通过。
- 未做真实浏览器视觉复验，未连接真实MySQL，未修改歌曲、标签或推荐数据；需用户刷新后台首页确认实际视觉比例。
