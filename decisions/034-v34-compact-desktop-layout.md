# v34 前台桌面紧凑布局

- 日期：2026-11-02。
- 依据：用户截图反馈每日推荐标题、横幅和模块过大，电脑需要过多下滚；关联排期 #004、#005 的前台体验局部修复，不代表两项整体闭环。
- 决策：保持现有导航和视觉配色，内容区域扩大到最多1440px；标题、卡片间距、歌曲行和歌单卡压缩。每日介绍改成横栏，移除装饰圆环，重复标题改为“为你精选”，算法细则默认折叠但可用键盘展开。
- 约束：保留歌曲名称字号、标签及推荐理由自然换行；手机单独适配44px触控目标及播放器底部留白。不修改推荐、收藏、请求、单实例播放器、后台或数据库，不安装依赖。
- 契约：specs/music/system/service-contracts.md“v34 前台桌面紧凑布局”。
- 验证：前端57项测试通过，包含新增3项静态布局契约检查；vue-tsc与Vite构建通过。现有大包体积警告仍在，不在本次修改范围。
- 限制：浏览器执行工具返回unsupported call，未进行实际页面尺寸、首屏歌曲数、点击和音频复验；不能把静态样式与模板检查称为视觉验收。用户刷新前台后需确认桌面与手机效果；无需重启后端。
