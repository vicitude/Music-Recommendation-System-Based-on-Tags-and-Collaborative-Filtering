# C1 新标签模拟数据

先盘点真实库，再确认处理范围，最后执行生成。未取得单独清理确认，不删除或覆盖旧模拟用户。新增formal-v1模式与独立默认前缀sim_c1_，旧模式保持兼容。生成模式只从启用的正式词库读取标签，不创建标签，不复活停用项，不改歌曲和真实用户。

八类画像使用新曲风/情绪/场景，固定种子，用户有随机兴趣和活跃度差异。按上海时间八档安排播放行为，画像有主要活跃时段并保留探索；收藏/评分时间与对应播放一致，避免全部堆在生成时刻。时间为人工模拟设定，不宣称真实用户习惯。

formal-v1拒绝复用任何已有目标用户名，避免重复运行混合旧版本数据；生成整体事务。旧模式保留原幂等行为。新增只读本机盘点入口，自动读取既有本机密码文件，只输出聚合账号/行为/标签/歌曲数量，无口令或个人数据。

C1完成条件仍包括真实库批准执行及验证；本轮隔离测试通过不算真实200人已重建，不进入C2正式比较。
