# B2 自动标签候选使用说明

更新：CLAP多片段分析已接入本页独立按钮，每次1至5首、结果仅候选；见docs/B2-CLAP多片段候选操作说明.md。下面规则系统仍独立有效，模型分数不等于规则置信度，也不会进入自动写标签链路。

重启后端，打开 `/admin/music/song/batch-import/`。扫描前勾选“同时生成自动标签候选”，报告下方可展开每首歌曲的分数、证据、规则/词库版本和分析状态。

## 规则与写入
- 分数是未校准的规则可靠度，不是模型概率或准确率。
- 嵌入曲风字段映射正式词库：0.85；文件名版本词：0.60；少量声学适配规则：0.60至0.65。
- >=0.75可选写入，0.55至不足0.75仅保留候选，低于0.55不输出；无依据允许为空。
- 导入时“仅对本次新建草稿写入高置信度标签”默认不选。开启还需标签创建权限，不改既有歌曲/人工标签，不重新启用停用标签。曲风2、情绪3、场景3上限。
- 旧批次没有分析时重新扫描；重复导入不会为既有歌曲补写标签。B3负责批量确认/拒绝及发布。

## 能力和局限
支持MP3 TCON、OGG GENRE、WAV INFO曲风字段及部分英文别名；未知值和数字曲风代码不硬猜。Remix、钢琴版、纯音乐等文件名词只提供候选，不能当作声音识别。

WAV采样前30秒，提取RMS/dBFS、频谱质心、过零率、能量变化、粗略BPM。短于5秒或静音不给声学标签；dBFS不是LUFS，BPM可能半倍/倍频。低能量/平缓片段给平静、放松、助眠候选，强节奏片段给活力、运动候选，均只中等分数。没有人声分类或深度模型，不判断悲伤、浪漫等语义情绪。

2026-11-09后续已复用用户提供的D:/ffmpeg/ffmpeg.exe（6.1.1），无需安装。重启原start_local入口即可自动检测并对本进程配置，不修改系统PATH。若从manage.py启动，可先设置PowerShell环境变量 `$env:LOCAL_IMPORT_FFMPEG='D:\ffmpeg\ffmpeg.exe'`；明确路径优先，无效时不静默回退。没有本地配置时仍可通过PATH查找。

只读验证40首结构通过的MP3全部分析成功，10首产生21条候选，高分候选0条。即规则覆盖25%，不是准确率，仍达不到大部分歌曲自动标注的目标。另4首MP3末帧不完整不进入分析，未改变B1安全边界。合成OGG对照也已实际解码通过，但不等于真实OGG歌曲验收。B2仍需评估预训练分类模型和标签质量，不为凑标签降低阈值。旧报告不会自动更新，需重新扫描；本轮没有真实库写入或素材复制。
