# B3 批次候选编辑

在批次表格提供“修改候选标签”，同页显示所选歌曲的三类复选框，无须打开正式歌曲编辑页。仅可编辑成功分析的歌曲；每类至少1项，上限曲风2、情绪3、场景2，只选启用字典项，不在此创建标签。

保存使用POST、CSRF及批次归属和标签写入权限校验，与分析/导入使用同一素材锁。原始模型候选和分数不改；人工候选单独记录账号、时间和指纹。保存后表格显示有效候选，导入前再次校验模型证据、字典状态及数量。重新分析成功或失败均清除该歌曲旧人工调整。修改仅影响以后新歌导入，不覆盖已有曲库；未保存的选项不进入导入。

验证包括持久化、越权/CSRF、未知歌曲/标签、数量/种类/停用项、证据篡改、再次分析失效、新歌采用和已有歌保护。无迁移、无新依赖、不代写真实曲库。
