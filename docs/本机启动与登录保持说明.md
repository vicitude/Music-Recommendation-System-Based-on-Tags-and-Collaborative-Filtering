# 本机启动与登录保持

## 密码文件

项目根目录的 `数据库密码.txt` 由本机启动入口自动读取。文件只保留一行项目专用数据库账户密码，密码原样读取，因此逗号、大小写和特殊字符均保留。文件已被 Git 忽略，不会上传；不要把内容发到聊天或提交到仓库。

也可以通过环境变量 `MYSQL_PASSWORD_FILE` 指定另一个本机密码文件。若密码文件不存在，启动入口才回退到隐藏输入；非交互启动不会把密码写入命令行或日志。

## 一键启动

在项目根目录双击 `启动后端.ps1`，或在 PowerShell 执行：

~~~powershell
Set-ExecutionPolicy -Scope Process Bypass
& ".\启动后端.ps1"
~~~

它仍会遵守端口占用、专用数据库和迁移确认门禁，不会强制结束未知进程。若8000端口已有后端，先在原窗口按Ctrl+C，再启动；这样不会误杀其他程序。

## 管理员登录保持

启动入口首次运行时会在项目根目录生成 `.django-secret-key`，该文件同样被 Git 忽略。Django会话继续写入项目数据库，登录Cookie默认保留14天且不随浏览器关闭立即失效。以后重启后端不会因为每次生成新密钥而强制退出。

仍可能需要重新登录的情况：手动退出、清理浏览器Cookie、超过14天、删除会话表、删除会话密钥文件，或切换浏览器配置。首次改用持久化密钥后，旧进程签发的会话可能需要登录一次；之后重启即可保持。

## 验证边界

自动读取只验证了本地启动代码和隔离测试；没有读取或输出你的真实密码，也没有代你连接真实MySQL。首次启动仍由你在本机确认迁移和管理员操作。
