# 一键选曲打标

扫描只读目录→同一紧凑表格列出歌曲/状态/三类标签→逐首选择或全选可分析歌曲→点击一次打标签。浏览器自动串行每组最多5首请求已有分析接口，保留180秒模型限时，不增加后台线程、队列或依赖。展示总进度、逐曲状态，停止按钮仅停止后续分组，当前分组完成并保存；刷新后已保存标签仍可见。页面关闭后不继续运行，明确不宣称持久后台任务。

JSON POST动作仍管理员权限/CSRF/批次归属/源指纹校验，错误清晰返回且不丢已有结果；逐组失败继续下一组，失败可重新勾选，网络状态不明不自动重试当前组。单组超时后客户端提示重载核对，不假装已取消服务器计算。新界面不展示旧规则长列表，兼容旧表单动作保留；无JS有每次5首表单兜底。

保存草稿位于列表之后独立确认，不将打标签当写正式曲库；已有歌曲不覆盖，新建草稿仍沿用原权限与三类数量验证。异常文件显示但不可选择，不放松严格扫描。页面只保留一个标题、内部滚动表格、全选/取消选择/选中数/进度；不会再要求用户每5首手动操作。

测试覆盖JSON权限/CSRF/错误/归属、每组数量保护、模板全选与进度、JS分组/停止/网络失败逻辑。浏览器不可用时明确视觉未验收，不称已实机通过。
