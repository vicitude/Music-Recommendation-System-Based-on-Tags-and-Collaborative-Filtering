# 扫描、选曲、一键打标签

## 批次内修改候选（v72）
打开已分析批次，在歌曲状态栏点击“修改候选标签”。页面上方展开该歌曲的曲风、情绪、场景复选项；每类至少1个，上限分别2/3/2，点击“保存候选标签修改”。保存后表格显示修改后的候选和“人工已调整”，之后一键导入会采用这些标签。原模型结果不改，人工选择不冒充模型置信度。

未保存就点发布不会采用未保存选项。重新打标会清除该歌曲之前的人工调整；已入库歌曲不被批次修改覆盖，要修改正式标签仍去歌曲编辑页。停用/超限/缺类标签在保存及导入前均检查。无需迁移或安装依赖，重启后端刷新批次页面即可使用。

本轮后端391项、打标脚本12项及规格环境门禁通过，未写真实MySQL，实际浏览器编辑待用户确认。用户反馈此前发布/前台等流程可用，属于用户验收证据，不称Agent实机验证。

## 最新简化操作（v68，取代下文必须先存草稿的旧流程）
在导入页面完成打标签后，直接到“③ 一键导入并发布”，勾选确认，点击“一键导入并发布新歌”，无需换页保存草稿再发布。只保存草稿保留为可选折叠项；已有歌曲不覆盖，已有草稿可用旁边“前往批量发布”链接处理。

若重启或关闭后找不到批次，打开页面顶部“找回最近批次”，点击对应时间及已生成标签数量的记录。批次保存到磁盘，不因重启主动删除，但仍受原账号及目录配置限制。空的发布页不是批次丢失证据。

## 新操作流程
重启后端后刷新 http://127.0.0.1:5173/admin/music/song/batch-import/ 。无需安装依赖或迁移。

1. 点击“扫描本地素材目录”。默认扫描只提取资料，不混入旧30秒声学分析。列出所有本批发现文件（最多500），异常/不支持的也显示原因，但不可选择分析。
2. 在同一张表内逐首勾选，或点击“全选可分析歌曲”。显示选中数量，可取消选择。
3. 点击一次“给选中歌曲打标签”。页面自动串行每组最多5首，逐组展示状态和总体进度，用户不必每5首操作一次。已完成标签直接填入同表三列。
4. 可点“停止后续处理”，当前组结束后停止，已保存结果不丢；网络/登录/超时异常则停止后续，请刷新核对，避免盲目重复计算。正常的单曲模型拒识/失败会显示原因，后续组仍继续。失败项可重新勾选打标。
5. 如要入库，另在表格下勾选确认保存新歌草稿及采用候选。打标签只是生成批次候选，不自动替换已有歌曲；重复指纹跳过。发布和标签编辑仍走现有歌曲编辑页。

## 体验与限制
### 批量发布（v67）
歌曲列表顶部和批量导入页顶部均新增“批量发布歌曲”入口，地址：http://127.0.0.1:5173/admin/music/song/batch-publish/ 。若看不到，重启本机后端并刷新页面，无需安装依赖或迁移。

保存新歌草稿后进入该页，逐首勾选或点击全选，勾选确认，再点“发布选中歌曲”。系统逐首检查音频、资料和三类标签；合格项发布，失败项保持原状并显示原因。已发布歌曲默认不列出，重复提交不改发布时间；标签不会重新生成或覆盖。全部已发布时会显示“目前没有待发布歌曲”，不是错误。
