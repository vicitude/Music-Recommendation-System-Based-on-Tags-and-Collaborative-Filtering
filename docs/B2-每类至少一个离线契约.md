# 每类至少一个候选：离线契约

用户初步认可多标签方向，要求分析成功歌曲每类至少一个：曲风1—2、情绪1—3、场景1—2。授权本轮只分析此前15首以外的25首，不改正式曲库或后台。旧v59“不采用整版”的判断被用户初步听感反馈修正为“可继续试用”，不等于真值验证通过。

保留v59全部文本、模型及独立双描述规则。某维没有达标标签时，按该维全部有效独立片段双描述均分选最高一项，记录evidence_level=LOW_FALLBACK、未达标原因、原始分数及补位来源，不伪装达标。不按歌名修改答案、不把补位占比当准确率。达标候选标记SUPPORTED_HEURISTIC，仍非概率或校准置信度。

场景先保留原联合规则建议；若为空，按最高情绪映射一个使用建议：狂欢/欢快→KTV，活力/热血励志→运动，自信→驾车，甜蜜/浪漫→约会，平静/放松/治愈→助眠，思念/孤独/悲伤/苦情/抑郁→夜晚。所有补位场景标记低把握、规则建议，夜晚表示聆听建议而非从音频识别时间，不改推荐时间上下文。规则是待试听的产品启发式，不声称安全性、睡眠或情绪效果。

只对三个质量OK、非重叠的有效音乐片段补位；若片段不足、异常分数、质量失败或每片段所有音乐描述都不领先非音乐对照至少0.05则保留失败/拒绝，不用最低数量绕过音频安全门禁。原始数据、结果保存新文件；总1200秒/无进展180秒监督、解码30秒，无新安装下载，不复制音频，不连接数据库、不写正式标签，失败不补样。

选样为40首基线指纹集合减去已完成v59的15首，严格检查40/15/25及互斥/并集、输入版本和指纹。同批样本早经模型诊断，非独立未见测试。成功样本每类数量断言，补位、拒绝、失败单独报告，任何失败不声称25首全部生成。后台旧场景上限3和可空仍未同步，正式接入另行实施。
