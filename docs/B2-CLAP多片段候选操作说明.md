# B2 CLAP多片段候选操作说明

## 页面操作
1. 重启原来的后端启动程序，打开 `http://127.0.0.1:8000/admin/music/song/batch-import/`。
2. 扫描本地目录，或打开本人之前保存的批次网址。原扫描规则候选与CLAP独立。
3. 在“CLAP 多片段候选分析”选择1至5首，点击“分析所选歌曲（仅生成候选）”。页面需要等待，没有后台任务队列。
4. 展开每首模型结果，查看片段起点、有效秒数、质量、模型/规则/描述/映射版本、候选原始相似度和拒识原因。
5. 不满足门槛时显示REJECTED并留空，不是强行给Top1；模型缺失/超时显示UNAVAILABLE，原草稿导入不受影响。

## 规则和限制
每首取前、中、后最多三个10秒片段，至少20秒才尝试，至少两个不重叠片段有效。短音频、静音、稳定窄带单音拒识，另有说话/噪声/单音描述对照。首版覆盖14种曲风、5种情绪的候选映射，不自动生成时间上下文或社交场景标签。

每标签两个固定英文描述。曲风平均余弦至少0.30、领先同维度第二名0.04；情绪至少0.30、领先0.05；还须两个片段同意、领先非音乐对照。门槛是未校准启发式，不是概率或准确率。完整契约见specs/music/system/clap-candidates-contract.md。

CLAP结果单独保存model_analysis，不合并进原规则标签列表；即使勾选原“高置信度标签写入”，也不会写入模型标签。不覆盖人工标签、不写Song/SongTag、不自动发布。B3的批量审核与发布尚未实现。

## 本机配置
权重默认项目local-ai/models/clap-htsat-fused，Git忽略；独立解释器默认用户目录AppData/Local/MusicRecommenderAI/clap-venv/Scripts/python.exe。可通过服务端环境变量LOCAL_IMPORT_CLAP_HOME和LOCAL_IMPORT_CLAP_PYTHON覆盖；FFmpeg沿用原LOCAL_IMPORT_FFMPEG配置，start_local自动检测D:/ffmpeg/ffmpeg.exe。

每次请求独立离线子进程，180秒整体超时、每片段解码30秒；最多5首。大曲库需分批，不代表已经支持500首模型异步任务。子进程只读取当前批次已核验文件，分析前后校验指纹；输入变化拒绝结果。无联网下载、无新增依赖/迁移，模型校验失败不使用。

## 本轮验证
后端全量359项、工具测试11项通过；三首真实MP3共九片段完成实际CPU分析，三首均拒识，无模型候选。它证明多片段及保守筛选执行成功，不证明自动标注已经有效；没有真实真值，不报告准确率，不能为增加输出而悄悄降低阈值。

本轮没有创建真实导入批次、写真实数据库、复制歌曲或修改标签。浏览器视觉/点击和MySQL实机验收未执行；子代理工具不可调用，未完成独立复核。后续须持续评估模型/描述与映射质量，B2整体质量仍未闭环。
