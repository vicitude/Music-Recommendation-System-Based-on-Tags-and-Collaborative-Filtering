# 前端页面与单播放器实施记录

日期：2026-10-30。范围：既定九类页面、同源API客户端、全局单播放器及离线交互验证。不是浏览器/MySQL/真实音频的端到端验收。

## 本轮实现

| 页面/组件 | 可操作功能 |
|---|---|
| 登录、注册 | 空白表单、校验、提交禁用、错误提示、会话与CSRF更新、登录后兴趣引导 |
| 兴趣引导 | 读取真实标签与既有选择，选择3—5项保存，跳过并清空兴趣 |
| 发现与详情 | 歌曲/歌手搜索、标签筛选、分页、元数据、授权来源安全链接 |
| 收藏 | 收藏、取消、分页、删除末页最后一首后恢复有效页 |
| 歌单 | 创建、详情、改名、显式二次确认删除；添加/移除歌曲，服务器成功后更新 |
| 每日推荐 | 原样推荐理由、保留原rank、按ID补元数据、空态、手动刷新及Retry-After倒计时 |
| 全局播放器 | 单audio跨页面保留在线曲目；原生播放/暂停/拖动，本地文件只创建objectURL，离页释放 |

App.vue使用既定原生hash路由和会话守卫。账户切换以用户ID和路径重建页面数据；公开发现/详情可匿名查看，在线播放和写入需登录。加载失败提供手动重试，不注入示例歌曲，不在localStorage存身份，不使用v-html。在线媒体地址限定本项目受控stream路径。

PLAY只由playing事件触发；performance.now累计实际播放墙钟时间，暂停、缓冲和拖动冻结，seek位置不转为收听时长。位置及累计均达到80%才请求COMPLETE，否则请求SKIP，最终有效性由后端复核。切歌等待旧PLAY结果再发终止；播放失败不补造完成。本地不发行为、不上传文件。网络断连保留同一个event_id和载荷，最多额外重试3次，间隔1/2/4秒；业务错误不自动重试。401清身份、取消待发重试并停止在线媒体；保护页跳登录。已发出的网络请求无法撤回，终态仍由后端幂等约束保护。

刷新推荐与注销接口不允许请求体，前端POST仅发方法及CSRF/JSON头，不发送`{}`。CSRF失败只更新校验信息并提示手动重试，不自动重复写入。登录成功后即使紧接的CSRF读取失败也保留登录结果，下一次写入重新获取token。

## 实际验证

| 验证 | 结果 | 证据边界 |
|---|---|---|
| Node前端测试 | 46/46通过 | API客户端11项、播放器19项、页面操作16项 |
| Vue/TypeScript检查及Vite构建 | 通过 | 模板编译通过；不是视觉布局或浏览器播放验证 |
| 后端回归 | 177/177通过 | config.test_settings内存SQLite与既有模拟媒体；不是MySQL |
| 文档门禁 | 通过，4项自测通过 | 24操作、16场景组、12性质及依赖一致性检查；不是功能验收 |

页面测试通过既有Vue自定义无界面renderer挂载实际SFC setup，注入模拟接口，执行页面操作；不渲染真实DOM或点击浏览器。覆盖服务端排序/解释、刷新空体及限流、兴趣上限、编码搜索、收藏/歌单接口与成功后更新、无效来源URL、密码不一致、末页消失、过期加载和重复提交。播放器测试注入音频端口和单调时钟，不解码任何音频；覆盖实际playing触发、冻结、双80%条件、切歌顺序、原载荷重试、失败不补造、会话重播、注销竞态和本地URL释放。

构建保留既有Element Plus全量注册，产生约1.04MB未gzip主脚本并出现大包警告（gzip约340KB）。未为消除告警调整既有依赖或扩大优化范围。

## 复核与查看

从项目根目录执行：

~~~powershell
npm.cmd test --prefix frontend
npm.cmd run typecheck --prefix frontend
npm.cmd run build --prefix frontend
& '.\.venv\Scripts\python.exe' -B backend/manage.py test music --settings=config.test_settings --verbosity=1
& '.\.venv\Scripts\python.exe' -I -B specs/music/system/verify_spec.py --self-test --check-environment
npm.cmd run dev --prefix frontend
~~~

最后一条启动前端开发页：`http://127.0.0.1:5173/#/discover`。API由Vite同源代理到127.0.0.1:8000。前端启动不等于后端/数据库可用：未启动已配置后端时页面显示接口错误，没有预置登录账号或虚假曲库。不得用test_settings运行持久演示库或宣称正式数据库已联通。

## 未完成与边界

- 当前会话的Node REPL工具入口返回unsupported call，未建立浏览器会话；没有执行浏览器点击、截图、布局、设备播放、实际解码或音频Range拖动验收，没有改走其他控制通道。
- 未连接MySQL、迁移、创建账号、启动后端/前端常驻服务、读取凭据、导入song/midi或发布用户音频。未新增或升级依赖，没有Git操作或删除文件。
- 后端会把有效收听限制在服务端PLAY到终止的时间内；网络延迟/重试下边界COMPLETE可能被拒，前端显示错误而不更换载荷伪造成功，真实网络下仍需实机验证。
- 下一步先确认专用开发数据库操作范围及合法音频发布证据，再验收登录→兴趣→推荐→播放→收藏/歌单→刷新；同时检查本地文件不上传、跨页单播放器、暂停/拖动不累计、离页释放及401退出。
- 完整CT/PT、MySQL并发、性能、真实推荐实验和论文效果结论均未完成。本轮测试不证明推荐准确率提升。
