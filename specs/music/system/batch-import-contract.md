# B1 批量本地音频导入契约

## 已批准范围的实现细化
B1 扫描 MP3/WAV/OGG、解析元数据、SHA256 去重、记录批次、确认后创建草稿并复制到媒体目录。复用 Song，不新增表、迁移或依赖；B2 自动标签和 B3 批量发布不在本阶段。封面只检出并记录，不抽取图片，不影响导入。

## 入口与权限
后台 `/admin/music/song/batch-import/`，需要活跃工作人员及 add_song/change_song 权限，POST 受 CSRF 保护。源目录仅由服务端 `LOCAL_IMPORT_SOURCE_ROOT` 指定，默认 `D:/AAA素材库/song`，不接受页面任意路径。拒绝链接/重解析路径，源目录、媒体和报告目录不得重叠。

批次为 UUID，绑定创建者，仅本人读取和执行。私有 JSON 报告保存在 Git 忽略的 `local-import-batches/`，不进入公开媒体。扫描不会写歌曲、复制音频或修改源目录。

## 扫描与元数据
每首最多30MiB、每批最多500首已识别音频；超限提示分目录继续，不声称完整扫描。忽略歌词，FLAC/M4A/MP4/AAC/WMA 明确列为不支持。逐块计算 SHA256、批内重复不导入，数据库指纹在执行时再次检查。

MP3 读取 ID3v2.3/v2.4/v1，按 MPEG Layer III 帧累计时长，不以首帧码率估算 VBR；WAV 按帧数计算并读取 INFO；OGG 读取 Vorbis/Opus 注释与结束采样位置。标题、歌手、专辑优先嵌入字段；缺失回退“歌手 - 歌名”或首个连字符，保留版本词。字段来源和错误原因必须记录，不能推断无分隔的歌手。缺失/超长字段待补充。格式结构检查不代表完整解码或试听。

扫描不调用旧身份猜测标签，正式自动标签在 B2 处理。

## 导入、重试与失败边界
明确勾选“创建草稿并复制音频”后才执行。执行前核对批次归属、目录配置、相对路径、链接、大小、SHA256 和结构；源文件发生变化必须重新扫描。使用同源目录文件锁串行导入，每首独立事务，一首失败不回滚成功项。已有指纹歌曲不覆盖；重复执行不创建重复歌曲或媒体。

草稿 active/playback_allowed/redistribution_allowed 均 false，checked_at null；无自动发布、标签或授权声明。随机媒体名复制到项目目录，原文件不变。报告记录逐首 created/skipped/failed 以及失败后未关联媒体路径，不擅自删除副本。报告保存失败时已提交记录仍可按指纹查重；这不是文件系统与数据库的分布式事务。崩溃造成的文件孤儿是已知风险。

## 验收
临时目录与内存 SQLite 覆盖三格式、VBR、编码、重复/损坏/超限/链接、批次归属、权限、CSRF、文件变更、草稿复制、幂等与失败重试。真实 MySQL、真实目录复制、浏览器视觉与试听另行验收，不用离线结果替代。
