# SPEC-MUSIC-001 一次性实施确认单

日期：2026-10-29确认范围，2026-10-30同步状态。规格门禁：17/17通过。24个API与媒体/行为/推荐后端已有177项测试通过；系统整体验收未完成。本文不能替代数据库或素材发布授权。

## A. 本轮可以进入开发的范围

1. **项目骨架**：Django 5.2.18后端、Vue 3.5.44前端、TypeScript 5.9.3、MySQL连接配置模板；使用现有.venv与前端锁文件。
2. **账户与权限**：注册、登录、注销、CSRF、同源会话、Django admin；不在前端保存令牌。
3. **曲库与标签**：Song、Tag、SongTag、三类标签、合法媒体草稿/发布、歌曲查询和分页。
4. **播放与行为**：合法在线播放Range、浏览器本地文件播放、收藏、歌单、PLAY/COMPLETE/SKIP幂等事件；暂停和拖动不累计listened_ms。
5. **核心创新**：标签内容画像 + User-CF双路融合；基于有效行为量的alpha；新用户标签引导；CONTENT/CF/HYBRID/HOT四种解释证据。
6. **每日推荐**：每日快照、60秒刷新限制、过滤下架/近期完成/收藏歌曲、无邻居与空库回退。
7. **验证顺序**：先离线门禁；再后端模型/服务/API测试；再前端typecheck/build；取得专用测试库授权后迁移测试；最后联调16+4新增场景、12项性质和性能测试。

## B. 本轮明确不做

- Redis、Celery、微服务、对象存储、云部署、分布式流计算。
- 深度学习、实时情绪识别、实时场景识别、MMR、多样性增强和Item-CF扩展。
- 商业音乐平台接口、未经授权的音频下载、公开互联网部署。
- Vue管理后台；曲库和媒体维护使用Django admin。
- 模拟行为冒充真实效果；没有许可证据的歌曲不进入可播放推荐。
- 第二套前端路由/状态管理框架；使用hash路由、原生fetch和单个HTMLAudioElement。
